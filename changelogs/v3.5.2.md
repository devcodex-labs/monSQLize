# monSQLize v3.5.2

> Release date: 2026-11-02
> Publication authority: the immutable tag and npm registry. An untagged checkout is a release candidate; the date above does not establish registry availability.

## Highlights

Patch release for documentation. There are no runtime or library changes: public APIs, defaults, bundle output and dependency versions are the same as 3.5.1.

## Documentation

- The Vector Search page no longer claims that no vector index lifecycle API is provided; it links the Search index page, which manages Atlas Search and Vector Search indexes since 3.4.0.
- `vectorSearch()` and the Search index pages are grouped under Search and vectors in the docs site, and the capability traceability tables gain a Search index row. Pages that belong in the sidebar but were unlisted are now published.
- A runnable `examples/docs/vector-search.ts` example is added, long Search index behavior tables are split for mobile, and terminology is unified across English and Chinese pages.

## Upgrade and rollback

No migration is required. Rollback to 3.5.1 is safe and changes only the packaged README and changelog.
