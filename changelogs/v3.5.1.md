# monSQLize v3.5.1

> Release date: 2026-10-28
> Publication authority: the immutable tag and npm registry. An untagged checkout is a release candidate; the date above does not establish registry availability.

## Highlights

Patch release for documentation and release tooling. There are no runtime or library changes: public APIs, defaults, bundle output and dependency versions are the same as 3.5.0.

## Documentation

- The README now states that MongoDB is supported (stable) today, with MySQL and PostgreSQL adapters as the next step, matching the docs site. It adds a native-driver vs monSQLize example.
- The docs site gains a 1200x630 `og:image` share card and `twitter:card=summary_large_image` / `twitter:image` meta. Page `description` meta now matches each page's language.

## Release tooling

- The release-candidate check treats HEAD as pushed when it is an ancestor of an origin branch, including after a newer commit becomes the tip. Shallow clones fetch and deepen history first. Local-only commits still fail.

## Upgrade and rollback

No migration is required. Rollback to 3.5.0 is safe and changes only the packaged README and changelog.
