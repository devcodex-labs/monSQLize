# monSQLize v3.3.3

> Release date: 2026-10-23
> Publication authority: the immutable tag and npm registry. An untagged checkout is a release candidate; the date above does not establish registry availability.

## Highlights

Dependency-only patch. Public entry points, Node.js `>=18`, build formats, cache generations and package budgets remain unchanged from 3.3.2.

## Changed

- Upgrade the pinned `schema-dsl` dependency from 3.0.4 to 3.0.5 (patch: preserves `type` alongside `enum` in fast-path validation, defers combined keywords to AJV, aligns regex Unicode semantics with AJV). No monSQLize API, type or package-budget change.

## Upgrade and rollback

No migration is required. Upgrading from 3.3.2 is a drop-in replacement; rollback to 3.3.2 restores `schema-dsl@3.0.4`. Schemas that combine `type` with `enum` are now type-checked on the fast path, which may reject values previously accepted by mistake.
