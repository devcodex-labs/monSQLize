# monSQLize v3.5.4

> Release date: 2026-11-13

## GridFS

- Reserve file IDs across uploads, resumable operations, deletion, rename, and orphan cleanup. State updates and cleanup bind to the session originally read, so late append, finalize, or abort calls cannot mutate a new upload after ID reuse.
- Stream resumable appends with bounded buffering and validate persisted chunks during finalization. Missing-chunk diagnostics list up to 1,024 indexes and report the total when truncated. Finalize returns the metadata for the file it committed, even if another operation deletes and reuses the ID before it returns.
- Repair stream teardown and retry handling, including early destruction, error delivery, and listener cleanup. Align deletion and regression coverage with MongoDB Driver 7.
- Verify stored chunks and digest provenance in audited recovery. Recovery enforces trusted digests for verified direct uploads and resumable uploads, and records discrepancies in metadata-only `uploadStream` SHA claims as warnings.
- Add a read-only, paginated orphan inspector for ObjectId file IDs. The inspector rejects an empty `--after-files-id=` cursor. The separate recovery utility requires a matching ownership snapshot and confirmed writer quiescence before it can apply changes.

## Search indexes

- Accept future server status strings in `SearchIndexStatus` and export `KnownSearchIndexStatus` for consumers that need the known values. The existing READY and queryable checks still govern `waitForSearchIndex`.

## GridFS upgrade and rollback

Pause GridFS mutations and drain every old writer before upgrading. Deploy while writes are paused, run `ensureIndexes()` to migrate the legacy `createdAt` TTL index to the idle-session `expiresAt` TTL index, and reconcile retained ownership records before reopening writes. Coordinate rollback with the same writer drain and resolve retained owners before restoring legacy writers.

See the recovery and migration runbook in [English](https://github.com/devcodex-labs/monSQLize/blob/v3.5.4/docs/en/gridfs-recovery.md) or [简体中文](https://github.com/devcodex-labs/monSQLize/blob/v3.5.4/docs/zh/gridfs-recovery.md).

No dependency versions changed in this release.
