# monSQLize v3.6.0

> Release date: 2026-11-13

## Vector Search

- Accept BSON vector subtype 9 int8 and packed-bit int1 query vectors in Collection and Model `vectorSearch()`. Finite numeric arrays remain supported. Binary inputs preserve effective bytes and padding, are captured before asynchronous execution, and remain separate in query-cache keys.
- Reject malformed or unsupported vector formats locally while preserving native server errors, scores, Model visibility filters and hydrated documents. Float32 Binary remains outside this convenience API; native aggregate pipelines remain available.
- Add the opt-in `npm run test:search:real` source matrix with random disposable databases, native-driver controls, failure reporting and cleanup. It covers automatic scalar/binary quantization, pre-quantized vectors, full-text scores, counts and same-collection rank/score fusion.
- Verify the Search matrix on Community 8.2.12 + mongot 0.69.1 and 8.3.13 + mongot 1.70.6. MongoDB 8.2 remains EOL, and fusion behavior on 8.2 belongs to its preview scope. These results do not establish compatibility for arbitrary mongod/mongot pairs.

## Documentation verification

- Report individual and combined documentation search-index sizes without fixed search-index byte ceilings. Required language indexes, other asset budgets, builds, links and browser checks remain enforced.
- Update bilingual quantization guidance and the runnable vector-search example for BSON inputs and current version pairings.

No dependency versions or Node.js runtime requirements changed in this release.

Users upgrading GridFS from before 3.5.4 must still follow the writer-drain and TTL migration procedure in the [3.5.4 notes](./v3.5.4.md).
